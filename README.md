# Personal Portfolio

A simple and responsive personal portfolio website built with HTML and CSS.

## About

This project presents a brief introduction and biography, along with personal information and skills in a clean and simple design.

## Technologies Used

- HTML5
- CSS3

## Features

- Clean and simple design
- Responsive layout
- Personal biography
- Easy-to-navigate interface

## Purpose

This project was created to practice web development and showcase my personal profile using HTML and CSS.
